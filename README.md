# CachyOS Hyprland dotfiles

A Hyprland Lua configuration for an HP ZBook Firefly 15 G8 (32 GB RAM, NVIDIA T500), with Noctalia v5, Kitty and an optional Waybar theme. Start with the **[installation and troubleshooting guide](docs/INSTALL.md)**. Noctalia supplies the default bar, launcher, notifications, wallpaper and lock screen; Waybar is an alternative bar, not a replacement for the rest of Noctalia.

The configuration uses automatic monitor detection and does not force a GPU or VA-API driver. Set display scaling and wallpaper for your machine after installation. Some personal shortcuts reference optional apps; see the guide.
